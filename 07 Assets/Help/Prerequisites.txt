# TenantIQ - Prerequisites

TenantIQ v1.0 is designed to run from a Windows administrative workstation using PowerShell 7 or later.

The supported entry point is:

  .\Start-TenantIQ.ps1

The launcher performs prerequisite validation before the TenantIQ main menu opens.

## Required Runtime

  Windows 10, Windows 11, or a supported Windows administrative workstation
  64-bit operating system
  PowerShell 7 or later (pwsh.exe)
  Internet access to Microsoft 365 authentication and administrative endpoints
  Permission to execute TenantIQ PowerShell scripts under organizational policy

Check the PowerShell version with:

  $PSVersionTable.PSVersion

TenantIQ v1.0 requires PowerShell 7+. Windows PowerShell 5.1 is not the supported TenantIQ runtime.

## Required PowerShell Modules

TenantIQ startup currently validates the following required modules:

  ExchangeOnlineManagement
  Microsoft.Graph.Authentication
  Microsoft.Graph.Reports
  Microsoft.Graph.Users
  Microsoft.Graph.Groups
  Microsoft.Graph.Applications
  Microsoft.Graph.Identity.SignIns
  Microsoft.Graph.Identity.Governance
  Microsoft.Graph.Identity.DirectoryManagement
  Microsoft.Online.SharePoint.PowerShell
  MicrosoftTeams

The following component is currently optional:

  PnP.PowerShell

If an optional component is unavailable, TenantIQ can still start. Controls that depend on unavailable optional capabilities may return INFO or another unscored result instead of a scored finding.

## Installing Required Modules

Run PowerShell 7 and install missing modules for the current user as needed.

Exchange Online:

  Install-Module ExchangeOnlineManagement -Scope CurrentUser

Microsoft Graph modules:

  Install-Module Microsoft.Graph.Authentication -Scope CurrentUser
  Install-Module Microsoft.Graph.Reports -Scope CurrentUser
  Install-Module Microsoft.Graph.Users -Scope CurrentUser
  Install-Module Microsoft.Graph.Groups -Scope CurrentUser
  Install-Module Microsoft.Graph.Applications -Scope CurrentUser
  Install-Module Microsoft.Graph.Identity.SignIns -Scope CurrentUser
  Install-Module Microsoft.Graph.Identity.Governance -Scope CurrentUser
  Install-Module Microsoft.Graph.Identity.DirectoryManagement -Scope CurrentUser

SharePoint Online:

  Install-Module Microsoft.Online.SharePoint.PowerShell -Scope CurrentUser

Microsoft Teams:

  Install-Module MicrosoftTeams -Scope CurrentUser

Optional PnP PowerShell:

  Install-Module PnP.PowerShell -Scope CurrentUser

Follow your organization's software installation and PowerShell repository policies before installing modules.

## Automatic Environment Validation

When you run:

  .\Start-TenantIQ.ps1

TenantIQ displays an Environment Validation section.

Statuses are:

  [OK]       Required component is available.
  [MISSING]  Required component is unavailable. TenantIQ will not continue.
  [OPTIONAL] Optional component is unavailable. TenantIQ can continue.

When a required component is missing, the launcher prints the corresponding installation action and stops before loading the assessment engine.

## Microsoft 365 Administrative Access

TenantIQ requires sufficient read access to retrieve the evidence needed by the selected workload. The exact Microsoft role, Graph scope, or service permission varies by control.

An account can authenticate successfully but still lack permission to retrieve specific evidence. TenantIQ should report that limitation as an unscored or unavailable-evidence result rather than assuming the tenant configuration is healthy or unhealthy.

Use an administrative account appropriate for assessment of:

  Exchange Online
  Entra ID
  SharePoint Online
  Microsoft Teams
  OneDrive
  Microsoft Intune
  Microsoft Defender
  Microsoft Purview

Microsoft Graph permissions requested by TenantIQ may require administrator consent.

## Authentication

TenantIQ uses Microsoft-supported authentication provided by Exchange Online PowerShell, Microsoft Graph, SharePoint Online, Teams, and other applicable Microsoft administrative interfaces.

Interactive sign-in and MFA are supported through Microsoft's authentication flow.

TenantIQ does not require Microsoft 365 passwords to be stored in TenantIQ configuration files.

Some workloads use isolated PowerShell processes to prevent authentication-library and module conflicts between Microsoft administrative SDKs. Additional Microsoft sign-in prompts can therefore be expected when moving between certain workloads.

## Network Requirements

The workstation must be able to reach Microsoft authentication and Microsoft 365 administrative endpoints. Connectivity can be affected by:

  Corporate firewalls
  Web proxies
  SSL inspection
  Conditional Access
  Endpoint security controls
  DNS or Internet connectivity

If authentication succeeds but a specific control cannot retrieve evidence, also verify tenant licensing, API availability, permissions, and service-specific requirements.

## PowerShell Execution Policy

Check the current policy with:

  Get-ExecutionPolicy -List

If TenantIQ scripts are blocked, follow your organization's approved PowerShell security process. Do not weaken enterprise security controls simply to run TenantIQ.

## TenantIQ Installation Integrity

Keep the TenantIQ directory structure intact. Do not independently move or rename framework, runtime, health-check, module, asset, configuration, or reporting files.

The supported launcher resolves dependencies relative to the TenantIQ installation directory.

Assessment output is written under:

  06 Output

## Before the First Full Assessment

Verify:

  1. PowerShell 7 is running.
  2. .\Start-TenantIQ.ps1 completes prerequisite validation.
  3. All required dependencies display [OK].
  4. The Microsoft 365 administrative account can complete MFA/Conditional Access requirements.
  5. The workstation can reach Microsoft 365 services.
  6. The TenantIQ directory is writable so assessment reports can be exported.
  7. Workloads are run from the TenantIQ main menu rather than by directly launching internal scripts.

After validation, run workloads 1 through 8 and then generate the Portfolio Report with option 9.
